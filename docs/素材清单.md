## 当前完成情况

核心图像已经生成并落盘：**海景一张、海妖三个姿态、船只三种配色**。字体已本地打包。

2026-09-21：两张模型生成的亮度遮罩已由 `art-source/bake-alpha.py` 烤进各自图集的 alpha 通道，遮罩文件从包内删除。原因是 iPad Safari 实测露出棋盘格——旧版 WebKit 不认 `mask-mode: luminance`，按 alpha 语义读 `-webkit-mask-image`，而遮罩处处不透明，等于没遮。烤进去之后不存在遮罩语义，任何浏览器结果一致；顺带省 734KB 并去掉启动时 157 万像素的主线程合成。

本清单只列实际文件。海草、海鸥、远景灯塔等目前包含在海景底图中，没有单独可移动的图层；不会将它们宣称为已完成的独立动画素材。

### 图集接入要点

- 每张图集分三列；单格宽为 `1774 / 3`，高为 887，比例 **2:3**。保持比例，不能把人物拉宽。
- CSS 使用 `background-size: 300% 100%`，位置为 `0% / 50% / 100%`。**不要再加 CSS 遮罩**，alpha 已在图里。
- **生成模型两次透明请求都返回 RGB 棋盘格**，当时改用模型另出的黑白遮罩分离。现在遮罩已烤进 alpha（`art-source/bake-alpha.py`），运行时不再需要遮罩。重新生成图集后必须重跑该脚本。
- 轮廓来自模型估计的遮罩，不是解析级抠图，仍须检查有没有切掉细线或出现浅边。透明区域近处保留了外扩的精灵颜色、远处铺白，缩放时不会把棋盘格灰拖进描边。
- 帧与帧只代表姿态切换，不是逐帧骨骼动画。漂浮、呼吸、下潜和发光由前端实现。

## 由前端实时绘制／排版

这些是程序组件，不需要继续用模型生成整张图片。

| 项目 | 实现范围 | 数据来源 |
| --- | --- | --- |
| 船队 | 每波入场、大小远近、漂浮、被拉动、触礁后保留 | `ship:in` / `ship:wrecked`，按真实船 id 管理 |
| 拉力与触礁效果 | 尾流、水纹、短暂闪光、角色光晕；不含血迹或碎裂惊吓 | 船只事件，只表达世界反应 |
| 旋律控制条 | 音块数量和音高位置、播放状态、实时声音指示 | `melody:phraseStart` / `attempt:pitch` |
| 准备提示 | 非数字圆点明灭，避免与船数形成第二套数字 | `attempt:countdown` |
| 船数 | 单句新增、最终累计；不同位置按状态互斥显示 | `phrase:result.newWrecked` / `game:finale.wreckedTotal` |
| 界面图标 | 麦克风、重听、返回、船数标识等简单线条图形 | 本地 SVG / CSS |
| 按钮 | 奶油白／珊瑚色、深色描边，正常／按下／不可用状态 | HTML / CSS |
| 分享卡 | 竖版排版，真实船数、海妖独白、复用海景与角色；提示截屏保存 | 终局数据 + 本地素材 |

## 不单独制作的素材

- 一百张不同的船：复用三种船图集。
- 每一个分数的结算图：船数和文案动态生成。
- 每个页面一张带字背景：保留场景与文字分离。
- 评分、评级、音准／节奏诊断图标：产品不需要。
- 原图的 `20 boats`、麦克风条和音符：前端重新绘制，不从参考图复制固定数值。
- 海妖鱼尾、像素字、夜海配色：用户新参考图已确定蓝发、浅蓝裙装与明亮手绘方向，不沿用被否定的设计。

## 发布前验收

下面七项已在 2026-09-20 用 `tools/test-ui.py`（真实 Chromium，桌面 1440×900 / 横屏 844×390 / 竖屏 390×844 三种视口，拒权点拍与合成麦克风两条完整路线）与 `node tools/pack.mjs --check-only` 复核，两条路线均为 PASS、0 条失败。

- [x] 全部实际引用的图像、字体正常加载，无棋盘格露边。脚本断言 `document.images` 无破图；截图逐张目视确认遮罩边缘没有露出棋盘格。
- [x] 海妖保持比例并坐在左侧礁石；三姿态不跳位。元素固定 `aspect-ratio: 2 / 3`，三姿态只切 `background-position`，截图中待机 / 唱歌 / 倾听三帧位置一致。
- [x] 船在远景与近景均可辨认，触礁状态有明确运动。远景船按 `depth` 缩小仍保留描边与旗帜；触礁船平滑移向停泊区并有一次闪光。
- [x] 首页只保留标题、PRD 副标题和「让她开口」主按钮。
- [x] 横屏、竖屏适配、分享卡无文字重叠或控件裁切。脚本断言三种视口下无横向溢出、无控件出界、同屏不出现两个船数。**竖屏此前有两处问题已修复**：船队整片浮在海平线以上的天空里，以及触礁船的停泊区整片落在海妖身后；现在竖屏用单独一组船队坐标，终局按钮下移到屏幕底部，详见 `docs/前端交付说明.md` §3。
- [x] 音块和船数由真实接口驱动；没有装饰性的假评分。脚本核对五次 `phrase:result` 之和、`ship:wrecked` 次数与 `getState().shipsWrecked` 三者一致，并扫描诊断话术关键词零命中。
- [x] 完整离线包通过资源引用、平台限制和 2 MiB 校验。实测包内 1804KB；打包校验现在同时扫描 CSS `url()` 与 JS 里的 `assets/` 路径，两者此前都不在检查范围内。

**仍需真机人工完成**：麦克风权限弹窗与采集、扬声器串音、WebView 性能、真人演唱的分数手感、海妖合成音色的听感。合成媒体流不能替代这几项。
