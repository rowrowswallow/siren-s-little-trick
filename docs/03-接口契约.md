# 前后端接口契约 v1.0

> **这份文档是给前端开发的。**
> 后端只通过 **5 个方法 + 1 组事件** 与前端通信，**不碰 DOM、不返回文案**。
> 后端挂载在 `window.Siren`，所有事件通过 `Siren.on(type, handler)` 订阅。
>
> 配套文档：`01-PRD.md`（产品意图）· `02-后端开发规格书.md`（后端实现）

---

## C1. API

```js
window.Siren = {
  init(options),          // → Promise<StateSnapshot>
  start(),                // 从 HOME 进入 PERM_REQUEST（必须由用户手势调用）
  replayPhrase(),         // 重听当前乐句（每句限 1 次）
  abort(),                // 中止本局，回 HOME
  on(type, handler),      // 订阅事件，返回 unsubscribe 函数
  off(type, handler),
  getState(),             // → StateSnapshot（同步快照，用于首帧渲染）
  version: '1.0.0'
};
```

### `init(options)`

| 选项 | 类型 | 说明 |
| --- | --- | --- |
| `seed` | number? | 固定旋律种子，**用于联调复现**。不传则随机 |
| `storagePrefix` | string? | localStorage 前缀，默认 `siren.` |

**调用示例**

```js
Siren.init({ seed: 4821 }).then(function (state) {
  render(state);                      // 首帧
  Siren.on('state:change', onState);
  Siren.on('attempt:pitch', onPitch);
  // ...
});

// 主按钮
btnStart.addEventListener('click', function () {
  Siren.start();                      // 必须在用户手势里调用，否则麦克风授权被拒
});
```

## C2. 状态机

```
'BOOT' | 'HOME' | 'PERM_REQUEST' | 'TUTORIAL' | 'LEARN_LOOP' | 'RHYTHM_FALLBACK'
| 'FINALE' | 'RESULT' | 'SHARE_CARD'
```

> `TUTORIAL` 为 **v1.1.0 新增**（新手引导关）：位于 `PERM_REQUEST` 之后、`LEARN_LOOP` 之前。
> 它的 `subPhase` 复用 `LISTEN` / `COUNTDOWN` / `RECORD`，但 **`phraseIndex` 恒为 0**
> 且不会推进；前端可用 `phase === 'TUTORIAL'` 区分这是教学关。
> 跳过或通过后进入 `LEARN_LOOP`，此时 `phraseIndex` 从 0 重新开始。

`getState()` 返回：

```js
{
  phase: 'LEARN_LOOP',
  phraseIndex: 2,          // 0..4
  totalPhrases: 5,
  subPhase: 'RECORD',      // 'LISTEN'|'COUNTDOWN'|'RECORD'|'ANALYZE'|'PULL'|'PHRASE_RESULT'
  shipsTotal: 100,
  shipsSpawned: 60,
  shipsWrecked: 41,        // ← 这就是"当前分数"
  seed: 4821
}
```

## C3. 事件表

| 事件 | 载荷 | 前端该做什么 |
| --- | --- | --- |
| `state:change` | `{ phase, subPhase, phraseIndex }` | 切换视图 |
| `melody:phraseStart` | `{ phraseIndex, notes[], eighths[], familiar, seed }` | 海妖开口动画 + 按 `eighths` 高亮音块 |
| `melody:titleReveal` | `{ title }` | 结算时揭晓歌名（仅熟曲且 ≥ 60 分） |
| `attempt:countdown` | `{ from: 3 }` 逐次下发 `3, 2, 1` | 倒计时动画 |
| `attempt:start` | `{ phraseIndex }` | 麦克风开始采集，音块条进入待点亮态 |
| `attempt:pitch` | `{ t, midi, cents, conf, voiced }` —— **每 50ms** | 音块实时点亮与配色 |
| **`attempt:note`** | `{ index, targetMidi, actualMidi, accuracy, tier, t }` —— **逐音一次** | **探针滑过该音时弹出档位反馈**（v1.1.0 新增，见 C5） |
| `attempt:end` | `{ reason: 'done' \| 'silence' \| 'timeout' }` | 停止点亮。**`silence` 时不做文字提示** |
| `ship:in` | `{ id, lane, depth, side, entryDelayMs, k? }` | 20 条船分批从两侧滑入；`depth` 决定缩放 |
| `ship:wrecked` | `{ id, pull }` | 该船滑向礁石 + 触礁闪光 |
| `phrase:result` | `{ phraseIndex, newWrecked, totalWrecked }` | V4：大字 `newWrecked` + 船队动画 |
| `game:finale` | `{ wreckedTotal, ending: 'A' \| 'B' \| 'C' \| 'D', seed }` | V5：大字 `wreckedTotal` |
| **`player:replay`** | `{ durationMs, parts[] }` —— **FINALE 开始时一次** | **回放玩家录音**（v1.1.0 新增，见 C5） |
| `melody:replay` | `{ notes[] }` | ⚠️ **v1.1.0 起终局不再使用**（原"全曲回放"已取消）。保留仅为兼容，前端可不再订阅 |
| `notice` | `{ code, level }` | 见 C4 |
| `error` | `{ code, message }` | 见 C4 |

### `notes[]` 元素结构

```js
{ midi: 62, startMs: 0, durationMs: 326, degree: 1 }
```

> 后端只给 MIDI 与时值。**音高频率换算、音块配色、像素图选择全部由前端决定。**
> 后端内部负责播放（海妖的歌声由后端合成），前端只需跟着 `notes[]` 做视觉同步。

### `attempt:pitch` 载荷

```js
{ t: 1234.5, midi: 64.3, cents: +18, conf: 0.86, voiced: true }
```

| 字段 | 说明 |
| --- | --- |
| `t` | 毫秒时间戳（相对于 `attempt:start`） |
| `midi` | 连续 MIDI 值（含小数，可直接映射到音块高度） |
| `cents` | 相对最近半音的音分偏差，−50 ~ +50 |
| `conf` | 置信度 0–1 |
| `voiced` | 是否检测到有效音高；`false` 时前端应让音块灰暗 |

## C4. 技术状态码（`notice` / `error`）

**后端不返回中文文案**，只给码，前端自己映射：

| code | level | 前端建议文案 |
| --- | --- | --- |
| `MIC_DENIED` | error | 如果您拒绝了麦克风权限，游戏就听不到您的声音咯 |
| `MIC_RETRY` | notice | 再点一下让她开口 |
| `NOISY_ENV` | notice | 周围有点吵，靠近一点麦克风 |
| `LOW_CONFIDENCE` | notice | 有点听不清，再靠近一点 |
| `NO_INPUT` | notice | **（建议不显示文字，改让海妖沉回水中）** |
| `STORAGE_FAILED` | notice | **（建议不显示）** |

### 前端文案规范（P4 / P5 强制）

- ❌ 不得出现演唱诊断：「第 3 个音低了」「你跑调了」「再大声一点」「别害羞」
- ❌ 不得显示四维拆解（音准 / 节奏 / 轮廓分数）
- ✅ 只有一个数字：**船数**
- ✅ 0 条的文案必须正向：「船走远了，她还在等你」

## C5. v1.1.0 新增事件（`attempt:note` / `player:replay`）

### `attempt:note` —— 逐音档位反馈

玩家演唱过程中，**每判定完一个音广播一次**（一句 3–7 个音 → 每句 3–7 次）。
用于"探针沿音块滑动，滑到哪弹出哪一档"的实时视觉反馈。

```js
{ index: 2, targetMidi: 67, actualMidi: 66.8, accuracy: 0.91, tier: 'great', t: 1304 }
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `index` | number | 目标音序号，0 起 |
| `targetMidi` | number | 目标音高（整数 MIDI） |
| `actualMidi` | number \| null | 实际唱出的 MIDI；**`null` = 漏音**（该窗口内没有稳定段） |
| `accuracy` | number | 该音相似度 0–1，连续值。供自定义表现（如粒子强度），也可忽略 |
| `tier` | string | `'perfect'` \| `'great'` \| `'good'` \| `'miss'` |
| `t` | number | 判定时刻，相对 `attempt:start` 的毫秒 |

**档位判定标准**（与打分器同源的容差参数，故不会自相矛盾）

| tier | 音分偏差 | 起音偏差 |
| --- | --- | --- |
| `perfect` | ≤ 50 | ≤ 150ms |
| `great` | ≤ 100 | ≤ 220ms |
| `good` | ≤ 200 | ≤ 400ms |
| `miss` | 其余，或漏音 | — |

**时序**：录音时间越过第 i 个音的**结束时刻**时判定并广播。末音在录音结束（或静默中止）后判。
因此 `t` 单调递增，但**不保证与 `attempt:pitch` 严格交替**——前端不要假设两者的相对顺序。

**与 P4 的关系**：这是**实时视觉反馈**，不是事后诊断话术。两条红线仍有效：

- ❌ 不做成文字诊断，只用视觉档位（颜色 / 图标 / 粒子）
- ❌ 结算页仍然只有一个数字：船数

> ⚠️ **不要把它渲染成"第 N 个音"这类定位文案**——那就变成 D7.4 明令禁止的诊断了。

### `player:replay` —— 回放玩家录音

`FINALE` 阶段开始时广播一次，告知前端"即将播放你自己的录音，时长 X"。
后端负责播放，前端据此做视觉同步（如波形条、海妖倾听动画）。

```js
{ durationMs: 11200, parts: [{ phraseIndex: 0, startMs: 0, durationMs: 2100 }, /* ... */] }
```

| 字段 | 说明 |
| --- | --- |
| `durationMs` | 实际回放总时长（**已去掉句间留白**；若超长则已按 1.2 倍速折算） |
| `parts[]` | 每句的片段信息，便于前端做分段高亮；`startMs` 是相对回放起点的毫秒 |

**行为约定**

- **不提供跳过**（产品决策）：前端不要渲染跳过按钮
- 回放前后端已 `releaseMic()`，麦克风不再采集
- **兜底模式（`RHYTHM_FALLBACK`）不发此事件**——没有录音，直接从 `FINALE` 进 `RESULT`
- `melody:replay` 在终局**不再发出**（原"海妖全曲加速回放"已取消）

## C6. 渲染提示（非强制，但踩过坑）

| 项 | 说明 |
| --- | --- |
| 船队布局 | 建议 5 条水平通道（`lane` 0–4）× 4 层深度，`depth` 映射缩放 0.6–1.0 |
| 入场 | 按 `entryDelayMs` 错开，从 `side` 侧滑入 |
| 性能 | 每波 20 条分批；触礁船转静态；停泊船可低频更新（如每 3 帧） |
| 像素风 | `image-rendering: pixelated`；整数倍缩放；避免亚像素模糊 |
| 安全区 | `viewport-fit=cover` + `env(safe-area-inset-*)`；**CSS 需过 Chrome 61 基线**（见 `.skill/.../css-compatibility.md`） |
| 结局 | `ending: 'A' \| 'B' \| 'C' \| 'D'` 对应 `01-PRD.md` §7.7 的四种结局 |
| 端能力 | `window.xhs.miniTool.*`（存相册 / 发笔记）。**必须先判空降级**，普通浏览器里为 `undefined` |

### 视图对照

| 视图 | 对应 phase / subPhase |

| V1 首页 | `HOME` |

| **V2c 新手引导关** | **`TUTORIAL`**（v1.1.0 新增；可跳过，跳过即进 `LEARN_LOOP`） |

| V5 终局 | `FINALE`（回放玩家录音）→ `RESULT` |
| V6 分享卡 | `SHARE_CARD` |
