# 《塞壬的小把戏》· 离线 H5 游戏

听海妖唱一句，再轻轻哼回来，看看能吸引多少条船。拒绝麦克风时可点击打拍，完成同一局游戏。

现已包含前端与后端：采用用户确认的明亮手绘海面、蓝发海妖和可爱船只，覆盖首页、主游戏、单句结算、终局与竖版分享卡。视觉参考优先于早期 PRD 中的像素风描述；只显示船数，不向玩家展示评分或诊断。

运行 `npm run serve` 后打开终端显示的本地地址；`npm run build` 生成离线 ZIP。素材清单见 [docs/素材清单.md](docs/素材清单.md)，前端接入与动效说明见 [docs/前端交付说明.md](docs/前端交付说明.md)。

## 输入电平自适应（针对低电平麦克风）

实测有设备的麦克风峰值只有 0.032 RMS（约 −30 dBFS），正常应为 −12 ~ −6 dBFS，
且 120 帧里 100 帧接近静音。离线验证证明 **YIN 在 0.003 RMS 以上就有 100% 检出率**，
所以瓶颈不是检测器，而是信号没被抬进可用区间。

`Audio.computeInputGain()` 会在每句录完后按实测峰值算出安全增益供下一句使用：

- 已经够响 → 完全不动（1x）
- 上限 8 倍；不允许把底噪抬到 0.02 以上；绝不削波
- **电平统计始终用原始缓冲**，增益只作用于检测副本

## 船队模型（2026-09 已按决策替换）

```
k ~ Uniform(0,1)  有界
触礁条件：k < score/100
```

单条船触礁概率**恰好等于 score/100**，因此一局期望触礁数 = 该句得分，
D9.3「长期期望严格等于分数」精确成立。两个端点由**构造**保证（不是概率）：

- `score = 0` → `k < 0` 恒不成立 → 必然 0 条
- `score = 100` → `k < 1` 恒成立 → 必然 100 条（满分会稳定触发结局 A）

单局波动服从二项分布 `B(100, score/100)`，50 分处 σ = 5.0。

`npm run curve` 可随时查看完整曲线与结局分布。
旧参数 `THRESHOLD_T` / `LURE_GAIN` / `K_MEAN` / `K_SIGMA` 已全部删除——
**不要再引入全局增益**，那会重新打破"触礁率 = 分数"。详见 `docs/规格问题清单.md` B1/B2。

## ⚠️ 术语约定（避免踩 PRD §6.2 的坑）

"音色"这个词在本项目里**特指后端合成的海妖嗓音**，绝不指玩家的声音。写文档和交流时请带定语：

| 说 | 指 | 出现在哪 |
| --- | --- | --- |
| **系统合成音色** / **海妖的音色** | 后端用 Web Audio 合成的 `siren` / `cue` / `tick` | `audio.js`。D14 步骤 2 验收的是**它** |
| **玩家音高** / **玩家演唱** | 麦克风采集后检测出的音高序列与起音时刻 | `pitch.js` → `segment.js` → `score.js` |

**玩家的音色、音量、颤音、气息一律不进算法**（PRD §6.2 明确要求，D0 也把"音色合成"归在后端产出侧）。
已实测确认：`score.js` 只读 `hz` / `midi` / `onsetMs`，**完全不引用 `rms`**——
音量只用于静默判定与起音点定位，不参与任何维度打分。

所以"验音色"这句话是不完整的，必须说清是"验**海妖的**音色"（开发期一次性听感验收），
否则容易被误解成要对人声做音色分析。

## ⚠️ 无法在本机验证的部分（必须真机人工验证）

离线环境只能验证纯逻辑。以下必须在真机 / 小红书模拟器里跑：

| 项 | 怎么验 |
| --- | --- |
| 麦克风采集（权限、采样率、`AudioContext` 解锁） | 打开 `js/probe/probe.html`（走 http，先 `npm run serve`） |
| 音高检测在真机上的耗时（目标 < 5ms） | 探针页的「性能」面板 |
| 端到端延迟（目标 < 150ms） | 探针页估算 + 录屏逐帧比对 |
| **海妖的合成音色**是否"3 秒内听得出是小星星"（D14 步骤 2 出口标准） | 人耳听。**这是对后端合成器的验收，与玩家声音无关** |
| 环境噪音下的识别率 | 探针页的信噪比与有音高帧占比 |
| 兜底模式能否拿满分 | 真机点拍 |

探针页只验证 A1/A2/A4/A5（麦克风、性能、采样率、噪音），**不验证海妖的合成音色**——
那只能靠耳朵听，且与被测者的嗓音条件无关。

## 平台硬约束（改代码必须守住）

`tools/pack.mjs` 会逐条扫描并在违规时**拦住打包**：

- 完全离线：禁 `fetch` / `XMLHttpRequest` / WebSocket，资源全部打包
- 脚本外置：禁内联 `<script>`、禁 `onclick=`、禁 `eval` / `new Function` / WASM
- 禁 Worker / Service Worker，逻辑全在主线程
- 禁用：定位、剪贴板、传感器、蓝牙、全屏、`window.open`、`window.prompt`
- 单页：一个 `index.html`，视图用 JS 切换；禁 iframe
- `index.html` 必须在 zip 根目录；总包 < 2MB（2026-09 决策，见 `docs/规格问题清单.md` B5）
- 后端不返回任何中文话术，只给技术状态码（契约 C4）
